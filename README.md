# 🔥 About SOLO Interface

SOLO Interface is a beginner-friendly cybersecurity toolkit written in Bash.  
It provides a hacker-style terminal interface with useful reconnaissance and enumeration tools for learning cybersecurity basics.

This project is designed for students and beginners who want to practice:
- Network Scanning
- Information Gathering
- Directory Bruteforcing
- Linux Bash Scripting

---

## ⚡ Features

- 🎯 Nmap Service & Version Scan (`-sCV`)
- 📂 Gobuster Directory Bruteforce
- 🌐 Whois Lookup
- 💻 Hacker Style Interface
- 🎨 Colorful Terminal UI
- ⚙️ Simple Bash Script

## 🛠️ Requirements

Install dependencies:

```bash
sudo apt install figlet nmap gobuster whois -y
```

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/neerajrajeev-in/solotools.git
Go to project directory:

```bash
cd Solotools
```

Make script executable:

```bash
chmod +x solo.sh
```

Run the tool:

```bash
./solo.sh
```
