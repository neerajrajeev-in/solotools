# SOLO Interface

SOLO Interface is a terminal-based hacking style toolkit written in Bash.  
It provides a colorful hacker-themed interface with useful networking and reconnaissance tools.

## Features
- Nmap Service & Version Scan
- Gobuster Directory Bruteforce
- Whois Lookup
- Animated Hacker Interface
- Colorful Terminal UI

## Requirements
- figlet
- nmap
- gobuster
- whois

## Installation

sudo apt install figlet nmap gobuster whois -y

## Run

chmod +x solo.sh
./solo.sh
